# CBSE-Result-Analyser-for-Schools
This was a small little project I worked on about 3 years ago at my high-school with my teacher. This is a python script which is fed with a text file of the school's result (CBSE) and it outputs all professional informations required to school in different excel files.
In this project, I also challenged myself to not using any python modules or library (except csv and math). Also it was one of my very first projects, from when I was a newbie, so it's a bit clumsy :)
